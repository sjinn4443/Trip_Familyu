# 거제도 가족여행

2026년 11월 20–22일, 엄마 · 아빠 · 수진 · 중희의 공동 여행 지도입니다.

`npm start`로 실행하고 http://localhost:4311/ 에 접속하세요. `npm test`로 자동 검증합니다.

구글 지도 장소 링크를 저장하면 가족 색상의 핀과 카테고리 아이콘이 표시됩니다. 주소와 영업시간을 백그라운드에서 확인하며, 불확실한 가격과 시간은 명확하게 표시합니다. 필수 방문지를 선택하고 적용하기를 누르면 근처 장소를 포함한 하루 코스를 추천합니다. 환율 기준일과 원·엔·루피아·파운드 환산 금액을 함께 제공합니다.

Railway에서는 `/data` 영구 볼륨을 사용합니다. 가족 이름은 표시용이며 로그인을 대신하지 않습니다. 링크에 접속한 사람이 공동 장소를 보고 수정할 수 있습니다.

기존 Ferrero Rocher Korea Trip 앱과 소스·저장 데이터·배포 프로젝트가 분리되어 있습니다.
